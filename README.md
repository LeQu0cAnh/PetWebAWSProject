\# Aria Eumi - Local AI Assistant



Dự án trợ lý ảo tích hợp AI cục bộ trên Unity.



\## Hướng dẫn khởi động

1\. Kéo mã nguồn (Pull) từ nhánh `nhanh-pet-new` về máy.

2\. Tải Lõi AI (Engine \& Model) tại link Google Drive: \[Dán link của ngài vào đây]

3\. Giải nén file Zip và chép vào thư mục `Assets/StreamingAssets/`.

4\. Mở Unity và nhấn Play. 



\## Lưu ý quan trọng

\- Không đẩy các file `.gguf` hoặc file thực thi (.exe) lên GitHub.

\- Mọi thay đổi về code vui lòng cập nhật lên nhánh `nhanh-pet-new`.
